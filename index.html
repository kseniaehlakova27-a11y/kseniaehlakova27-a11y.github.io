Автоматизация обработки планировок

Разработка модуля чтения чертежей плана секции и формирования документа для отдела аналитики по шаблону. Автор: Ксения Ехлакова

О работе

Тема ВКР

«Разработка программного модуля для автоматизированного чтения чертежей планировок секции и формирования отчётных документов для отдела аналитики компании-застройщика».

Актуальность

В компании-застройщике обработка планировок квартир до сих пор выполняется вручную: специалисты вырезают фрагменты планировки из чертежа и вручную переносят данные в отчётные таблицы. Это медленно, трудоёмко и приводит к ошибкам. При большом объёме проектов такой подход становится «узким местом» для отдела аналитики. Автоматизация этого процесса позволит ускорить подготовку данных, снизить влияние человеческого фактора и освободить время специалистов для анализа, а не механической работы.

Проблема, которую решает проект

  • Планы планировок квартир извлекаются вручную из общих чертежей секции.
  • Данные по каждой квартире (площадь, комнатность, этаж, номер) заполняются вручную.
  • Высокий риск ошибок и расхождений между чертежом и отчётным документом.
  • Много времени уходит на рутинные операции вместо аналитики.

Как работает решение

План планировки секции загружается в программу, которая распознаёт квартиры на чертеже и автоматически формирует документ по заданному шаблону для отдела аналитики.

Ключевые задачи

  • Изучить структуру чертежей планировок секций и требования отдела аналитики к документам.
  • Проанализировать существующие подходы к распознаванию чертежей и выбрать подходящие инструменты.
  • Разработать модуль чтения плана секции и выделения планировок квартир.
  • Реализовать автоматическое формирование документа по заданному шаблону.
  • Провести тестирование на реальных чертежах и оценить точность и экономию времени.
  • Оформить документацию и подготовить презентацию к защите.

Инструменты и технологии

  • Языки программирования: Python, JavaScript
  • Обработка изображений и распознавание: OpenCV, Tesseract OCR
  • Формирование документов: шаблонизаторы (docxtpl / python-docx), экспорт в PDF
  • Веб-интерфейс: React
  • Базы данных: PostgreSQL
  • Инструменты: Git, Figma, VS Code

Ожидаемый результат

  • Сокращение времени обработки одного плана секции за счёт отказа от ручного вырезания и ввода.
  • Снижение количества ошибок при переносе данных в отчётность.
  • Единый формат документов для отдела аналитики, соответствующий шаблону.
  • Готовый к внедрению программный модуль, который можно масштабировать на новые проекты.
